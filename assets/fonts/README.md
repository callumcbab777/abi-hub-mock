# Fonts (free Google fonts, self-hosted)

Callum's choice (option A): Montserrat for all headings, nav, buttons and labels, Newsreader for body copy, and Inter as the fallback.

| Role | Font | Licence | File |
|---|---|---|---|
| Headings, nav, buttons, labels | Montserrat | SIL OFL 1.1 | montserrat.woff2 |
| Body and numerals | Newsreader | SIL OFL 1.1 | newsreader.woff2, newsreader-italic.woff2 |
| Fallback | Inter | SIL OFL 1.1 | inter.woff2 |

The files are Latin-subset woff2 builds of the Google Fonts releases. The stacks live in `assets/css/site.css` `:root` (`--font-display`, `--font-ui`, `--font-body`).
